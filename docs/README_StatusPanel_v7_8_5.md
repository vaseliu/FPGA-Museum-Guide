# v7.8.5 统一状态面板

下载 `MuseumGuide_StatusPanel_v7_8_5.bit`。接线与 TF 卡保持原样。

左上角使用一整块半透明背景，依次显示：

1. 数芯天下。
2. 当前图像模式。
3. 亮度、不透明度。
4. 缩放百分比。
5. **分辨率：640×480**。

分辨率取自 HDMI 输出的有效像素尺寸。本次输出仍为640×480；显示器面板的物理像素数量、BMP 文件原始尺寸和当前图片缩放百分比是其他信息，不用于这行。

沿用原有界面开关操作：KEY3 长按约2～3秒后松开，切换叠加界面。所有左上角文字、背景和状态方块在同一帧边界一起显示或隐藏；缩放行不再单独留在屏幕上。原有频谱也沿用同一个开关。

诊断字母数字行保持隐藏。左挥下一张，右挥暂停/继续轮播；上、下挥仍无操作。原按键缩放、效果切换和 AA 初始化验证保留。

本次没有增加分辨率切换或改变 HDMI 时序。文字格式直接使用显示模块的 H_ACTIVE/V_ACTIVE 参数，仿真另外验证了800×600和1920×1080参数下的三/四位数字排版；这不表示当前比特流支持输出这些其他模式。

## 验证与构建

本次检查了分辨率字形实际 RGB、整块背景连续、关闭时完整面板区域无残留、帧边界同步隐藏/恢复、原中文文字及各模式/透明度/亮度/缩放标签。最终建立/保持时序见配套记录，实板仍需下载确认。没有重新运行完整 BMP 像素/音乐回归。

源码中 `tools/build_td.py` 用于构建，`tools/test_status_panel.py` 用于本次面板测试。加 `--preview` 可以输出 RTL 渲染的开/关状态 PPM 图。工具路径沿用本机 E:/game 的 TD/ModelSim 安装。
