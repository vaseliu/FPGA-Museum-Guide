# v7.8.3 手势操作

下载 `MuseumGuide_Gesture_Horizontal_v7_8_3.bit`，保持现有接线和 TF 卡内容。

| 手势 | 功能 |
|---|---|
| 左挥 | 下一张图片 |
| 右挥 | 暂停／继续图片自动轮播；音乐继续 |
| 上挥 | 无操作 |
| 下挥 | 无操作 |

原按键缩放和切换效果功能保留：KEY3 短按切换效果；按住 KEY3 点按 KEY2，缩放按 100% → 50% → 75% → 100% 循环。

保留 v7.8.2 的 AA 兼容验证：四次稳定 ID、A5/5A/FF 寄存器写读验证、50 kHz I²C，以及屏幕诊断码。初始化成功仍显示 `20 AA 80` 和绿色状态块。修改没有改变传感器初始化、FIFO 读取、方向识别算法和原按键逻辑；只关闭手势动作层的上下挥操作。

程序仍会读取并处理传感器数据；上、下挥不再产生缩放脉冲或效果切换。模块旋转会改变物理方向，请保持原安装朝向。

SDA 接 J2 第1脚（P4），SCL 接 J2 第2脚（N4）；VCC 接 J2 第29脚3.3V，GND 接 J2 第30脚；VL 可接 J1 第29脚3.3V，INT 不接。排针方向以1、2脚标记为准，断电插拔。

本次验证包括上下手势无动作、左右操作、从 I²C FIFO 到播放器动作的集成仿真、原按键缩放/效果/透明度等回归，以及最终综合布局布线时序。没有代替实板测试，也没有重新执行完整多媒体像素/音乐回归；具体范围见配套验证记录。
